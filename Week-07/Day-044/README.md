## 🧠 What is a SOC?

A **Security Operations Center (SOC)** is a centralized team responsible for:

* Monitoring security events
* Detecting suspicious activity
* Investigating incidents
* Responding to threats
* Maintaining organizational security posture

The SOC operates continuously to ensure threats are identified and mitigated quickly.

---

## 👨‍💻 SOC Analyst Responsibilities

### 🔹 Level 1 (Tier 1)

* Monitor alerts
* Perform initial triage
* Investigate suspicious logs
* Escalate confirmed incidents

### 🔹 Level 2 (Tier 2)

* Deeper investigation
* Threat hunting
* Correlation analysis

### 🔹 Level 3 (Tier 3)

* Advanced threat detection
* Malware analysis
* Incident response coordination

## 📊 SIEM Fundamentals

A **SIEM (Security Information and Event Management)** system:

* Collects logs from multiple sources
* Normalizes data
* Correlates events
* Generates alerts

Common log sources:

* Firewall logs
* Authentication logs
* Endpoint logs
* Web server logs
* IDS/IPS alerts

---

## 🔍 Log Analysis Concepts

SOC analysts review logs to identify:

* Failed login attempts
* Unusual IP addresses
* Privilege escalation attempts
* Suspicious process execution
* Data exfiltration indicators

Understanding normal behavior is critical to identifying anomalies.

---

## 🚨 Alert Triage Process

Typical workflow:

1. Alert is generated by SIEM
2. Analyst validates the alert
3. Determine false positive vs real incident
4. Gather evidence (logs, timestamps, IPs)
5. Escalate or close case

Key concepts:

* False Positives
* True Positives
* False Negatives
* Risk prioritization

---

## 🧩 Incident Response Basics

Basic incident response stages:

1. Identification
2. Containment
3. Eradication
4. Recovery
5. Lessons Learned

SOC analysts are typically involved in identification and containment phases.
