## 🧠 What Are Logs?

Logs are records of events generated by systems, applications, and network devices.

They provide visibility into:

* User activity
* System behavior
* Network connections
* Application errors
* Security events

Logs are essential for monitoring, troubleshooting, auditing, and forensic investigations.

---

## 📂 Types of Logs

### 🖥️ System Logs

* Operating system events
* Service start/stop events
* Authentication activity

### 🌐 Network Logs

* Firewall logs
* Router logs
* IDS/IPS alerts
* VPN connections

### 🔐 Security Logs

* Login attempts (successful/failed)
* Privilege escalation
* Account lockouts

### 🧩 Application Logs

* Web server logs (Apache/Nginx)
* Database logs
* API logs

---

## 📊 Log Structure

Most logs contain:

* Timestamp
* Source IP / Host
* Event ID
* Username
* Action performed
* Status (success/failure)

Understanding log structure is critical for filtering and correlation.

---

## 🔎 Basic Log Analysis Techniques

Common investigation techniques:

* Searching for failed logins
* Identifying unusual IP addresses
* Detecting repeated authentication attempts
* Reviewing abnormal process execution
* Correlating timestamps across systems

Command-line tools often used:

```bash
grep "Failed password" auth.log
cat access.log | grep "POST"
awk '{print $1}' access.log | sort | uniq -c
```

---

## 🚨 Detecting Indicators of Compromise (IOCs)

Logs can reveal:

* Brute force attacks
* SQL injection attempts
* Suspicious outbound connections
* Malware execution traces
* Lateral movement attempts

Correlation across multiple log sources improves detection accuracy.

---

## 🔄 Log Analysis in Incident Response

During an investigation, analysts use logs to:

1. Identify initial access
2. Determine attack timeline
3. Identify compromised accounts
4. Detect persistence mechanisms
5. Confirm containment effectiveness

Logs are often the primary evidence source in SOC environments.

---

## 🛡️ Security Relevance

Understanding logs is fundamental for:

* SOC Analysts
* Incident Responders
* Threat Hunters
* Detection Engineers

Strong log analysis skills improve detection capability and reduce incident response time.
