# 🧪 Hands-on Labs

This directory contains **practical labs and experiments** performed in controlled environments as part of the **365 Days of Cybersecurity** project.

The goal of these labs is to **apply theoretical knowledge**, gain hands-on experience with real tools, and document findings in a clear and professional way.

---

## 🎯 Purpose of the Labs

The labs focus on:

* Reinforcing concepts learned during daily study
* Practicing real-world cybersecurity tools
* Developing an offensive security mindset
* Creating reproducible and well-documented exercises

Each lab is designed to be:

* **Safe** (no unauthorized testing)
* **Educational** (learning-focused)
* **Documented** (commands, observations, conclusions)

---

## 🗂 Lab Structure

Each lab follows a simple and consistent structure:

```text
labs/
└── lab-name/
    └── README.md
```

The lab README typically includes:

* Lab objective
* Environment description
* Tools used
* Commands executed
* Observations and key takeaways

---

## 🧰 Topics Covered

Labs may include (but are not limited to):

* Network scanning and enumeration (Nmap)
* Traffic analysis (Wireshark, tcpdump)
* Cryptography fundamentals
* Linux security basics
* Web security fundamentals (later stages)

The complexity of labs will increase progressively.

---

## ⚠️ Legal & Ethical Notice

All labs documented here are conducted in:

* Local virtual machines
* Deliberately vulnerable systems
* Authorized learning platforms (e.g., TryHackMe)

⚠️ **No real-world systems are tested without explicit permission.**
This content is strictly for **educational purposes**.

---

## 📈 Continuous Improvement

Labs will be added and refined over time as new tools and techniques are learned.
Earlier labs may be revisited to improve documentation or depth as skills progress.

---

🔴 *Theory builds knowledge. Labs build skill.*
