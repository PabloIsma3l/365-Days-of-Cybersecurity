# 🧠 Overview

In this room, I performed a **SOC-style investigation** involving:

* Email analysis
* OSINT techniques
* Domain and infrastructure investigation
* Metadata extraction
* Correlation of multiple data sources

The scenario simulated a real-world case where an invitation email led to suspicious activity, requiring deeper investigation.

📌 Key Concept:

Security investigations are about **connecting small pieces of evidence into a full picture**.

---

# 🎯 Learning Objectives

* Analyze suspicious emails
* Extract indicators from messages and attachments
* Perform OSINT-based investigation
* Investigate domains and infrastructure
* Correlate data to identify malicious activity

---

# 📧 Email Analysis

The investigation started with a suspicious invitation email.

---

## 🔍 Key Elements Analyzed

* Sender address
* Embedded links
* Email content
* Attachments

---

## 🚨 Suspicious Indicators

* Unusual sender domain
* Social engineering elements
* Embedded external links
* Possible phishing intent

---

📌 SOC Insight:

Email is often the **initial attack vector**.

---

# 🌐 Domain & Infrastructure Investigation

Extracted domains were analyzed using OSINT techniques.

---

## 🔎 Key Steps

* Domain lookup (WHOIS)
* Reputation checks
* IP resolution
* Infrastructure mapping

---

## Indicators Identified

* Suspicious or newly registered domains
* Lack of legitimate history
* Possible attacker-controlled infrastructure

---

# 🧬 Metadata Analysis

Files and artifacts can contain hidden metadata.

---

## 🔍 Extracted Information

* Author names
* Creation timestamps
* Embedded data

---

📌 Why It Matters:

Metadata can reveal:

* Attacker identity clues
* Tools used
* Timeline of activity
