# 🧱 What is Alert Triage?

Alert triage is the process of:

* Reviewing alerts generated by detection systems
* Investigating underlying data
* Determining severity and validity

---

## 🔹 Possible Outcomes

* ✅ True Positive → confirmed threat
* ⚠️ Suspicious → requires further investigation
* ❌ False Positive → benign activity

---

📌 SOC Insight:

Triage is about **reducing noise and identifying real threats**.

---

# 🔎 Splunk Fundamentals

Splunk is a SIEM platform used to:

* Ingest logs
* Search data
* Visualize events
* Investigate incidents

---

## 🔹 SPL (Search Processing Language)

Core tool for analysis.

---

## Example Queries

Search all logs:

```text id="d7v3kq"
index=main
```

---

Filter for failed logins:

```text id="n4c2xp"
index=auth_logs action=failure
```

---

Search for PowerShell activity:

```text id="z9m1tr"
process_name=powershell.exe
```

---

📌 SPL enables precise filtering and investigation.

# 🚨 Alert Investigation Workflow

---

## 🛡️ Step-by-Step

1. Receive alert
2. Identify key indicators (IP, user, process)
3. Query Splunk for related logs
4. Analyze event details
5. Correlate activity across timeline
6. Determine alert classification

---

📌 Core Principle:

➡️ **Investigate before acting**

# 🧠 Triage Decision Making

---

## Key Questions

* Is the activity expected?
* Does it match known attack patterns?
* Is there evidence of compromise?
* What is the impact?

---

## Classification

* True Positive → escalate
* False Positive → close
* Suspicious → monitor / investigate further
