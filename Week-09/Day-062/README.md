## 🧠 What Are SOC Workbooks?

SOC Workbooks are structured investigation templates that:

* Standardize analysis steps
* Ensure consistency across analysts
* Reduce human error
* Speed up repetitive investigations

They typically include predefined queries, enrichment steps, and decision trees.

---

## 🔎 What Are Lookups?

Lookup tables are reference datasets used to enrich and validate alert data.

Examples include:

* Known malicious IP lists
* Internal asset inventory
* User privilege lists
* Known service accounts
* Geographic IP mappings

Lookups provide immediate context during investigations.

## 🧩 Example Investigation Flow Using Workbooks

1️⃣ Alert triggered in SIEM
2️⃣ Analyst opens relevant workbook template
3️⃣ Execute predefined queries
4️⃣ Enrich data using lookup tables
5️⃣ Assess severity and impact
6️⃣ Document findings
7️⃣ Escalate if required

## 🧰 Common Use Cases for Lookups

* Validating whether an IP is internal or external
* Checking if a user is part of privileged groups
* Identifying known false positive patterns
* Cross-referencing threat intelligence indicators
