## 🧠 What is Alert Triage?

Alert triage is the process of:

* Reviewing security alerts generated by monitoring tools
* Validating whether the alert is legitimate
* Determining severity and impact
* Deciding whether escalation is required

The goal is to filter noise and focus on real threats.

---

## 🏢 Role of a SOC L1 Analyst

A Level 1 SOC Analyst is responsible for:

* Monitoring SIEM dashboards
* Investigating triggered alerts
* Performing initial analysis
* Gathering context and evidence
* Escalating confirmed incidents to L2/L3
* Documenting findings clearly

L1 analysts are the first line of defense.

---

## 🔎 Systematic Triage Methodology

### 1️⃣ Validate the Alert

* Identify the detection rule
* Understand why the alert was triggered
* Check timestamp and affected assets

### 2️⃣ Gather Context

* Source and destination IP addresses
* Username involved
* Hostname and asset criticality
* Related logs (authentication, network, endpoint)

### 3️⃣ Investigate Indicators

* Suspicious processes
* Unusual login patterns
* Known malicious IPs/domains
* Multiple correlated alerts

### 4️⃣ Classify the Alert

* False Positive
* True Positive (Low/Medium/High severity)

### 5️⃣ Escalate if Necessary

Escalate when:

* Malicious activity is confirmed
* There is lateral movement
* Privileged accounts are involved
* Sensitive systems are impacted

---

## 🚨 False Positive vs True Positive

### 🔹 False Positive

* Legitimate administrative activity
* Automated system behavior
* Misconfigured detection rule

### 🔹 True Positive

* Confirmed malicious behavior
* Indicators match known attack patterns
* Clear impact on security posture

Reducing false positives improves SOC efficiency.

---

## 📊 Importance of Documentation

Clear documentation must include:

* Alert summary
* Investigation steps taken
* Evidence reviewed
* Final classification
* Escalation details (if applicable)

Good documentation ensures smooth handover between SOC levels.
