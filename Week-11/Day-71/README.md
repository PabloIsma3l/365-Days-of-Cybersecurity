# Day 71 - Splunk Investigation Lab

## Overview

On Day 71 of my **365 Days of Cybersecurity** journey, I completed the **"Investigating with Splunk"** lab from TryHackMe.

This lab focused on performing a security investigation using **Splunk SIEM**, analyzing log data to identify suspicious activity and understand the sequence of events that occurred on a compromised system.

---

## What I Practiced

During this lab I practiced several important Blue Team and SOC analyst skills:

* Log analysis using Splunk
* Writing basic SPL queries
* Investigating Windows Event Logs
* Identifying suspicious command execution
* Understanding how attackers create persistence on a system
* Investigating network activity to identify suspicious URLs

---

## Key Concepts Learned

Some of the key concepts reinforced during this lab include:

* **EventID 4720** – Used to detect when a new user account is created.
* Investigating suspicious commands such as `net user /add`.
* Using log correlation to reconstruct attacker activity.
* Identifying potential indicators of compromise within system logs.
