## 🧠 Investigation Approach

During security investigations, analysts typically follow a structured process:

1. **Collect data** – Gather logs and telemetry from available sources
2. **Identify anomalies** – Look for suspicious patterns or unusual behavior
3. **Correlate events** – Connect multiple events across different systems
4. **Determine attacker activity** – Understand what actions were performed
5. **Document findings** – Record evidence and conclusions

This methodology helps analysts understand the scope and impact of potential incidents.

---

## 🔎 Key Investigation Concepts Practiced

### Log Analysis

Logs provide visibility into system and network activity. Analysts review logs to detect indicators of compromise such as:

* Failed authentication attempts
* Suspicious IP addresses
* Unusual user activity
* Abnormal system behavior

---

### Event Correlation

Security investigations rarely rely on a single event. Analysts correlate events across different log sources to build a clearer picture of attacker activity.

Example correlation steps:

* Identify suspicious login attempts
* Check the originating IP address
* Investigate subsequent actions performed by the account

---

### Incident Identification

By analyzing patterns and correlating events, analysts determine whether the activity represents:

* Normal system behavior
* Misconfiguration
* Suspicious activity
* A confirmed security incident
