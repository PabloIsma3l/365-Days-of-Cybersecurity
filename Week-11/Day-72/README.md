## 🧠 What Are Logs?

Logs are **records of events** generated by systems, applications, and network devices.

They provide visibility into what happens inside an environment and are essential for:

* Troubleshooting
* Security monitoring
* Incident response
* Forensic investigations

Without logs, it would be extremely difficult to determine **what happened during a cyber attack**.

---

## 📚 Why Log Analysis Is Important

Security analysts rely on logs to:

* Detect suspicious activity
* Investigate security alerts
* Track attacker behavior
* Reconstruct incidents

Logs are often collected and analyzed using **SIEM platforms** such as:

* Splunk
* Elastic Stack (ELK)
* QRadar
* ArcSight

These tools centralize logs and allow analysts to search, correlate, and visualize events.

---

## 🧾 Common Sources of Logs

Logs can be generated by many different systems within an organization.

Examples include:

### Operating Systems

* Windows Event Logs
* Linux system logs

### Network Devices

* Firewalls
* Routers
* Switches

### Security Tools

* IDS/IPS
* EDR platforms
* Antivirus

### Applications

* Web servers
* Databases
* Authentication systems

Each log source provides a different perspective of activity within the infrastructure.

---

## 🔎 Common Log Fields

Most logs contain several key fields used during investigations.

Typical log attributes include:

* **Timestamp** – when the event occurred
* **Source IP** – origin of the activity
* **Destination IP** – target system
* **Username** – account involved in the action
* **Event ID** – identifier for the type of event
* **Action / Status** – result of the operation

Understanding these fields allows analysts to **correlate events and detect suspicious behavior**.

---

## 🛡️ Logs in SOC Operations

In a Security Operations Center (SOC), logs are used to:

* Detect potential security incidents
* Investigate alerts
* Identify attacker techniques
* Support threat hunting activities

Logs are usually aggregated into a **central log management system or SIEM**, where analysts perform investigations.

---

## 📊 Example Log Entry

Example of a simplified log entry:

```
2026-03-13 10:22:45
User: admin
Source IP: 192.168.1.45
Action: Failed login attempt
Status: Denied
```

From a single event, an analyst can determine:

* who attempted access
* when the attempt occurred
* where it originated from
* whether it succeeded or failed

Multiple events combined help reveal **patterns such as brute force attacks or unauthorized access attempts**.
